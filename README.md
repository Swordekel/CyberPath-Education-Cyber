# 🧠 CyberPath — Platform Pembelajaran Keamanan Siber

CyberPath adalah platform edukasi interaktif berbasis web yang dirancang untuk membantu mahasiswa dan profesional memahami dasar hingga lanjutan **Cyber Security** melalui kuis, materi pembelajaran, dan sistem leaderboard kompetitif.

---

## 🚀 Fitur Utama

### 🎯 **Kuis Interaktif**
- Kuis dengan berbagai topik: *Keamanan Aplikasi Web, Kriptografi, Forensik Digital, Hardening Sistem, dan lainnya.*
- Sistem penilaian otomatis dengan XP & poin.
- Fitur **anti-spam score** — satu akun hanya dapat menyelesaikan kuis sempurna satu kali.

### 🏆 **Leaderboard Dinamis**
- Ranking global berdasarkan total skor dan XP.
- Tampilan podium elegan dengan visualisasi medali 🥇🥈🥉.
- Persentase progres dan jumlah percobaan ditampilkan secara real time.

### 📊 **Dashboard Cerdas**
- Menampilkan progress belajar, XP, poin, dan rekomendasi kursus.
- Desain elegan dengan animasi halus dan efek cahaya neon.
- Akses cepat ke modul, kuis, dan lab virtual.

### 🧩 **Integrasi dan Struktur Modular**
- Backend: **Laravel 12.x (PHP 8.4)**
- Frontend: **Blade + TailwindCSS + Framer Motion**
- Database: **MySQL / MariaDB**
- Struktur modular dengan *Seeder* otomatis untuk quiz & pertanyaan.

---
## ⚙️ Instalasi Lokal

### 1️⃣ Clone Repository
```bash
git clone https://github.com/Swordkel/CyberPath.git
cd CyberPath
```

### Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
